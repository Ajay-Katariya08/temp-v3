Customization

Prompt allows you to easily customize the styling as well as content of the common elements including top navbar or heros.

Customize Styling (CSS)

Prompt comes with the power of CSS. css lets you use features that don't exist in CSS yet like variables, nesting, mixins, inheritance and other nifty goodies that make writing CSS fun again.

You can easily modify the themes by simply changing few variables. You even don't need to change anything in Prompt's source code. You can easily defined the override variables in src/assets/css/theme.css.
